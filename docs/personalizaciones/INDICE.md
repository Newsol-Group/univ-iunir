# Índice de personalizaciones · instancia G3Forge

**Estado:** pendiente de relevamiento estático sobre fuentes reales del cliente.

Al ejecutar `inicializado.md` con código disponible, registrar la rama/commit, fecha de lectura, procedencia conocida, cobertura completa/parcial/no leída y fichas `PERS-###` agrupadas por funcionalidad. Una personalización entre varias aplicaciones tendrá una ficha única.

No se inventan IDs, operaciones, pruebas, aprobaciones ni estados de despliegue. La carpeta preparada no indica ausencia de personalizaciones en servidores.
